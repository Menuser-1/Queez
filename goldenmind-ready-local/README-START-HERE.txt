GOLDENMIND — LOCAL READY PACKAGE
=================================
Frontend API URL is configured to http://localhost:3000/api.
A local backend .env with a generated JWT secret is included.
No OpenAI API key is included, so daily questions rotate from the built-in question bank.

WINDOWS:
1. Install Node.js 18+ and Python 3.
2. Double-click START-WINDOWS.bat.
3. First run installs backend dependencies (internet needed for npm install).
4. Browser opens http://localhost:5500.

MAC / LINUX:
1. Install Node.js 18+ and Python 3.
2. Run ./START-MAC-LINUX.sh from this folder.

This runs locally on your computer; it is not hosted publicly on the internet.
For online hosting, a hosting account and deployment are still needed.
Do not share backend/.env publicly.
